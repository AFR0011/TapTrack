## Current release rule

TT-B002 implementation is mechanically green on exact head `2e01cda7e69e80a4b75fa2bcea20f253fb4ebbc5`: publication guard, dependency audits, lint without errors, typecheck, 32/32 Vitest files (172/172 tests), production build, 9/9 route smoke, and both offline-mobile Playwright projects pass in GitHub Actions run `34206762454`.

That automated gate is necessary but not sufficient for production promotion. Release remains blocked until documentation is frozen, a READY Vercel preview exists for the final head, the disposable-account provider-backed walkthrough is completed, public-history/demo artifacts are reviewed, and the owner explicitly approves promotion.

Native Safari/iOS behavior, the empty-cloud claim/seed TOCTOU, IndexedDB-at-rest exposure, and JavaScript-number precision are residual limitations unless separately remediated; they must not be erased by release wording.
